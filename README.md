# Vishanti Petition 🏛️

A digital platform for submitting, tracking, and managing public grievances.

Vishanti Petition aims to make grievance management more accessible and transparent by bringing complaint submission and administration into one platform.

## Features

- **Complaint Submission** — Submit grievances through a centralized interface.
- **Complaint Tracking** — Track submitted complaints.
- **Duplicate Detection** — Identify potential duplicate complaints.
- **Admin Dashboard** — Manage complaints through a centralized interface.
- **Audit Trail** — Maintain records related to complaint activity.

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- Express
- PostgreSQL
- Drizzle ORM
- Supabase

## Getting Started

### Prerequisites

- Node.js
- npm
- PostgreSQL and the required database configuration

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd vishanti-petition
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the project root and configure the environment variables required by the application.

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Why Vishanti Petition?

Grievances can be difficult to organize and follow up on when information is scattered across different channels. Vishanti Petition explores a centralized approach to complaint management, with the goal of making submissions easier to handle and track.
